# Input data

Put the files from the task archive here:

```
data/
├── global_map.png      # satellite panorama, 3645×1845
└── crops/
    ├── crop_0.png      # 50 UAV "photos", 640×640, crop_0 … crop_49
    ├── ...
    └── crop_49.png
```

Frames must be sorted numerically (crop_2 before crop_10), not alphabetically.
